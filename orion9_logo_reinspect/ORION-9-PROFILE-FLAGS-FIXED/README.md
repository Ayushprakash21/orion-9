# ORION-9

ORION-9 is an AI-native supply chain operating system.

## Project

- React + TypeScript + Vite
- Express development/production server
- Single authoritative application source under `src/`
- Product identity is fixed to **ORION-9**
- Descriptor/tagline: **AI-Native Supply Chain Operating System**

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

## Branding

ORION-9 is the canonical product name. Legacy persisted branding values such as the retired SCM OS name are normalized to ORION-9 by the branding repository so stale browser/server configuration cannot resurrect the old product identity.
