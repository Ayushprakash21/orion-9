# ORION-9 MASTER SCM 0→100 CAPABILITY MATRIX & ARCHITECTURAL SPECIFICATION

## 1. Executive Overview

Orion-9 is an enterprise-grade Operating System and autonomous Supply Chain Management platform built with zero simulated mockups or client-side storage fallbacks. Every transaction, lifecycle transition, calculation, and governance rule is backed by **authoritative Cloud Firestore collections**, strict multi-tenant isolation, real-time reactive event architecture, deterministic business logic engines, and a governed DEMO / LIVE database control plane.

## 3. Database Authority & Governance Rules

1. **No Client Authority**: Client components never persist local modifications directly without sending transactions through authoritative engine services and Firestore security rules.
2. **Deterministic Validation**: Calculations (ATP, Working Capital, 3-way match, Tax/Duty, Carbon Intensity) are computed deterministically by verified engines.
3. **Multi-Tenant Isolation**: Every document contains strict `tenantId` fields validated in Firestore security rules (`request.auth.token.tenantId == resource.data.tenantId`).
4. **Environment Isolation**: DEMO mode synthetic generation cannot write to LIVE database; LIVE mode is immune to synthetic data generator invocations and resets.
