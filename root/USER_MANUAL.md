# ORION-9 User Manual

## Operating model
ORION-9 is organized around a continuous operating loop:
**Sense → Understand → Simulate → Decide → Govern → Execute → Measure → Learn**.

## Mission Control
Use Command Center as the primary operational landing workspace. Review supply-chain health, exceptions, recommendations, and actions requiring attention.

## Autonomous Operations
Open **Autonomous Operations** from the ORION application launcher. This is the unified user map for:
- Supply Chain Digital Twin
- Event Fabric
- Decision Engine
- Scenario Lab
- Specialized AI Workforce
- Integration Fabric
- Master Data Intelligence
- Financial Intelligence
- Supply Chain Risk Graph
- Closed-loop Automation
- AI Governance
- Learning / Outcome Loop
- Ask ORION
- Decision History

Each tile opens the existing ORION-9 workspace responsible for that capability.

## Ask ORION
Use natural language to investigate demand, inventory, procurement, suppliers, logistics, risk, cost, and decisions. For material changes, prefer **Ask → Simulate → Review impact → Approve/Autopilot → Measure outcome**.

## Governance
Manual, Copilot, and Autopilot behavior is governed by platform policies and user permissions. External-system writes must only be considered complete when the connected integration and execution policy actually authorize the action.

## Decision history and learning
Use Decision Replay, Outcomes, and Decision DNA to understand previous recommendations, approvals, actual results, and policy evolution.

## Responsive operation
The ORION-9 operating experience is designed for desktop, tablet, and mobile. On mobile, prioritize Mission Control, Decisions, Ask ORION, Exceptions, and Approvals.

## ORION-9 OS Controls
- **SHUT DOWN** is available on the authentication footer and starts the same governed ORION-9 shutdown sequence used by the operating system.
- The authentication pages retain the cinematic ORION-9 startup/post-login flow; no generic loading replacement is used.
- The live supply-chain wallpaper uses the procedural globe/network composition with animated orbiting intelligence paths.
